# 🗺️ 요깃거리 (Yogitgeori)
> **"여기에 있는 즐길 거리"** — 위치 기반 혼잡도 필터링을 통한 랜덤 관광 및 AI 참여형 미션 서비스

공공 관광 데이터와 LLM(대형 언어 모델)을 결합하여, 유저에게 한적한 로컬 명소를 추천하고 현장 참여형 AI 미션을 제공하는 2026 관광데이터 활용 공모전 프로젝트입니다.

---

## ✨ 핵심 기능 (Core Features)
- **🎲 혼잡도 기반 랜덤 추천**: 관광지 집중률 데이터를 활용해 붐비지 않는 한적한 로컬 관광지 풀(Pool)을 무작위 추천합니다.
- **🚨 위치 기반 스토리 팝업**: 유저의 실시간 GPS를 트래킹하여 목적지 반경 진입 시 장소의 역사와 서사를 팝업으로 안내합니다.
- **🎙️ AI 음성 도슨트 & 미션**: 한국관광공사 Odii API 스크립트를 기반으로, LLM이 정제한 오디오 가이드와 현장 참여형 퀴즈/미션을 생성합니다.
- **♿ 배리어프리(Barrier-free) 필터**: 이동 약자(유모차, 휠체어 사용자 등)를 고려한 맞춤형 관광 코스 필터를 제공합니다.
